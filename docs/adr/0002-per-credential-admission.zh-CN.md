# 以每份上游凭证约束本地推理并发

用户已确认，所有上游凭证按每份凭证独立设置并发上限，每份凭证跨模型共享额度，同一邮箱的 Codex 和 BPS 授权分别计数。统一默认20，现有未设置上限的凭证也采用20，已有单独设置保留；限制由当前 CPA 实例在执行准入处实施，CPAMP 管理设置和展示运行状态，登录 Worker 不承担推理限流。

选择凭证作为边界，可以让同一通道的刷新和补登录延续原设置，也保留两种授权独立运行的约定。本地限制不采用邮箱合并，不声称控制上游平台的官方并发，也不复用 Home 控制面的权威并发协议。

未绑定凭证的满额请求等待整个兼容池，空闲后重新走原调度；已绑定会话只等原凭证，最多等待30秒。选择全池等待可利用先释放的兼容容量，因此公共等待数单独展示，不重复归入每份凭证，也不承诺严格的请求先到先服务。
