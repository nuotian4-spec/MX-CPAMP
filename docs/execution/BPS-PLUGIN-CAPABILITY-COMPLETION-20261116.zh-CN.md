### 1. 许可证：固定接口、原生紧凑展示

在“插件 → 已安装”的 BPS 区域显示一行许可摘要和“管理许可”，详情沿用现有弹层组件。展示许可状态、脱敏授权码提示、绑定 IP、有效期和最近错误；不新增主导航，不修改凭证原有五块。

管理动作复用当前连接的受作用域约束 API 客户端，经现有 Manager/CPA 管理通路访问：

| 操作 | 插件管理接口 | 请求 |
| --- | --- | --- |
| 读取许可状态 | `GET /v0/management/cpa-bps/license` | 无授权码正文 |
| 激活 | `POST /v0/management/cpa-bps/license/activate` | `{"license_key":"用户当次输入"}` |
| 刷新许可 | `POST /v0/management/cpa-bps/license/refresh` | `{}` |

- 展示条件不依赖 `active=true`。BPS 已配置但未注册时保留“插件未注册，许可未核实”的摘要；操作区只在插件已注册、状态接口可用、当前管理连接有效时启用。
- 接口 404、网络失败、响应缺失或未知代码分别呈现，不统一解释为未激活；`active`、`required`、`code` 依据真实响应解析。
- 读取状态与刷新许可是不同动作；刷新可能触发供应商交互，不在打开页面或后台轮询时隐式发送 POST。
- 激活、刷新均由管理员明确触发；点击后防重复提交。超时或结果不明只核状态，不自动重发 POST，不自动重装或重启。
- 请求固定当前 CPA 连接；切换连接、退出登录或关闭详情后清理输入、忽略旧响应，旧连接的请求不得落到新连接。
- 授权码仅作当次输入，使用密码框；不加入 URL、浏览器持久存储、通知、日志或证据。显示用供应商 `key_hint`，错误文本须避免回显授权码和代理认证信息。
- 许可文件归供应商插件管理，本站不复制一份授权状态作为权威源，也不改写许可验证。包内说明的落盘与网络验证行为属于供应商合同，尚非本站真实验收。

### 2. 配置：复用已有表单，只补已知交互

沿用 `GET /plugins/{id}/config` 与 `PATCH /plugins/{id}/config`：

| BPS 字段 | 推荐呈现 | 保存边界 |
| --- | --- | --- |
| `session_proxy_pool_enabled` | 开关 | 依实际注册类型保持布尔语义 |
| `session_proxy_pool` | 每行一个代理的多行编辑区 | 先核实际类型；字符串保留字符串，不擅自转换成 JSON 数组 |
| `session_proxy_idle_minutes` | 分钟数输入 | 依实际注册类型校验，不另造供应商取值范围 |

当前采用局部 BPS 展示适配，按插件 ID 与确切字段名匹配；不为一个多行控件修改 Go 插件 ABI 或建立通用动态动作框架。开关和数值仍走通用编辑器，不另做一张代理池页面；不把 Kilo 的独占、累计账号或容量规则强加给 BPS。

只 PATCH 用户改过的字段。后端现有规则是顶层浅合并：未碰的键保全，修改整个 object 字段会替换该字段，`null` 表示删除；PUT 整体替换不作为本次表单保存方式。代理 URL 可能含认证信息，只在配置详情按编辑需要呈现，不放进摘要、日志或错误回执。

类型未被当前表单支持时明确提示，不把当前未知类型降为字符串的行为当成兼容保证。未声明的新字段不猜测、不插入默认值。

### 3. 状态：操作异常优先，许可独立显示

最近维护区首先呈现真实操作状态，如“任务中断，需核实恢复”或“安装失败”；下方分别显示活动版本、运行注册和商业许可。`recovery_required` 不再被“许可尚未验证”覆盖。

当前未注册只定位一次最小错误：已有宿主日志中该次 BPS 加载/注册失败的原因、对应操作和活动版本。不靠重启、再次安装或真实激活来制造诊断证据；本地界面补齐可以与这项现场取证分开推进。

### 4. 后续升级：按能力合同判断，不按 ZIP 上传成功判断

| 新版变化 | 是否需要再改 CPAMP | 条件 |
| --- | --- | --- |
| 修复插件内部逻辑，既有许可和配置接口不变 | 通常不需要 | 宿主兼容、实际注册成功，复用既有界面 |
| 新增标准配置字段 | 通常不需要 | 注册返回受支持的 `config_fields` 类型 |
| 新增插件自带资源页面 | 导航与加载通常不需要 | 返回有效菜单与资源；页面自身业务和鉴权仍须满足既有合同 |
| 现有许可接口增加兼容字段或修复逻辑 | 既有功能通常不需要 | 既有请求、状态语义及副作用不变；新展示内容不自动生成 |
| 新增原生按钮、授权流程或特殊控件 | 需要小范围适配 | 当前没有动作声明或特殊控件元数据 |
| 不兼容的接口、配置类型或插件 ABI | 需要组合适配与发行 | 不把替换插件库当成完整宿主升级 |

供应商资源菜单可复用现有加载通路，但公开资源 GET 不等于管理写权限，iframe 也没有通用凭证桥。保留 BPS 原 `index.html → /oauth?provider=cpa-bps` 特例；新资源必须区分用途。

ZIP 清单目前没有完整功能/API/UI 合同。安装前展示“附带面板不覆盖本站；新增能力是否承接须在注册后核实”；注册后只列实际配置字段、资源入口及已支持原生动作。无需从压缩 HTML/JS 推测能力，也不将 `license_required` 视为某个许可动作已可用。

若后续供应商愿意稳定声明能力与显示提示，再协商版本化的可选元数据；未有合同前不承诺“所有未来功能零适配”。本次不引入任意 URL/方法执行器、不注入供应商整套 HTML、不执行包内安装脚本。
