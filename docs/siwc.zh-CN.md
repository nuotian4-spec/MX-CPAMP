# SIWC 账号绑定

SIWC（Sign in with ChatGPT）绑定在已有 Codex OAuth 账号上。绑定后仍使用原来的 Codex 账号身份、通道和代理设置。

## 使用入口

在“凭证管理”中打开 Codex 凭证详情，进入“配置”中的“OpenAI SIWC”区块。支持绑定的普通文件凭证显示“绑定 SIWC”或“重新绑定”；Home、运行时及其他不支持的凭证显示只读说明。

1. 点击绑定，复制或打开生成的授权链接。
2. 在浏览器中完成授权。跳转到 `http://127.0.0.1:1455/auth/callback?...` 后，复制地址栏中的完整地址。
3. 将完整地址粘贴回 CPAMP 并提交，保留所有查询参数，尤其是授权服务签发的 `client_id`。
4. 等待授权结果。提交被接收后仍可能处于等待状态；只有授权成功并回读账号状态后，界面才确认完成。

远程部署不要求服务器开放 1455 端口。浏览器显示本地回调地址连接失败时，可以复制完整地址回到 CPAMP 提交。

## 状态与取消

- `off`：本地未启用 SIWC。
- `valid`：内核判断本地 SIWC 凭证有效。
- `invalid`：本地 SIWC 凭证需要检查或重新绑定。

状态来自内核保存的凭证摘要，不会为了显示状态自动发起模型请求。

授权会话有效期为五分钟。过期或 CPA 重启后，需要重新生成授权链接。切换连接或账号后，旧会话的响应不会更新当前账号。

取消结果以服务端确认为准。若授权已经进入提交阶段，取消可能未生效；界面会按同一会话的实际结果更新，不会把“未取消”当作“绑定成功”。

## 适用限制

需要提供 SIWC 管理接口的 CPA 内核，以及启用本功能的 CPAMP。旧内核会显示不支持，不会自动改走普通 Codex 登录。此入口不提供独立创建 SIWC 账号、解绑或启用开关。

完整授权链接、回调地址和会话状态只用于当前绑定过程，不保存到浏览器持久存储。不要把包含授权参数的完整地址贴到公开日志或问题报告中。
